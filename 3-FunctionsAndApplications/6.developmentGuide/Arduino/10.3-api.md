# 6.1.3 API description

The `MyCobotBasic` C++ API is **identical** on the UNO R4 and the M5Stack —
same class, same methods, same semantics. Only the transport underneath
changes. The full method list is in the official
[API description](https://github.com/elephantrobotics/mycobot_docs/tree/main/myCobot_280_for_Arduino_en/3-FunctionsAndApplications/6.developmentGuide/Arduino/10.3-api.md).

This page covers only what differs.

## `setup()`

```cpp
MyCobotBasic myCobot;

void setup()
{
    myCobot.setup();
}
```

On the M5, `setup()` initialises the screen, power management and microphone
before opening the serial port. On a non-M5 board all of that is compiled out:

```cpp
void MyCobotBasic::setup()
{
#if defined MyCobot_M5
    delay(500);
    M5.begin(true, false, true);
    M5.Power.begin();
    dacWrite(25, 0);  // disable mic
    delay(500);
#endif
    mycobot_serial.begin(BAUD_RATE);
}
```

So on the R4 it reduces to `Serial1.begin(1000000)`. You must still call it.

## Unavailable on the R4

Guarded by `#if defined MyCobot_M5` and therefore absent:

| Feature | Reason |
|---|---|
| `MyCobotSaver` (`saver` member) | needs SPIFFS — ESP32 filesystem |
| `MyCobotLanguage` | includes `M5Stack.h` |
| screen / button / speaker helpers | M5 hardware |

`MyCobotSaver.cpp` is wrapped entirely in `#if defined MyCobot_M5`, so it
compiles to nothing on the R4. It is still required for the include chain to
resolve.

## Data types

Unchanged, and worth noting because they differ per arm model:

```cpp
constexpr const int Axes   = 6;
constexpr const int Joints = 6;
using Coords = std::array<float, Axes>;    // x, y, z, rx, ry, rz
using Angles = std::array<float, Joints>;  // J1..J6
```

A myCobot 280 is 6-axis. The myPalletizer types in the same header
(`MyPalletizerAngles`, 4 joints) are for a different arm — using them against a
280 silently truncates.

## Example

```cpp
#include <MyCobotBasic.h>

MyCobotBasic myCobot;
Angles angles = {0, 0, 0, 0, 0, 0};

void setup()
{
    myCobot.setup();
    delay(100);
    myCobot.powerOn();
    delay(100);
}

void loop()
{
    myCobot.writeAngle((Joint)J1, 100, 30);
    delay(1000);
    myCobot.writeAngles(angles, 50);
    delay(5000);
}
```

Identical to the M5 version — the only difference is the `ParameterList.h`
profile it is compiled against.
