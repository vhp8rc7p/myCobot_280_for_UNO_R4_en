# 6.1.5 LED matrix

The UNO R4 WiFi has a 12x8 LED matrix where the M5Stack Basic has a 320x240
LCD. It is far more limited, but enough for status text.

The R4 **Minima** has no matrix; this page applies to the WiFi only.

## The blocking problem

The obvious API is:

```cpp
matrix.beginText(0, 1, 0xFFFFFF);
matrix.println("myCobot");
matrix.endText(SCROLL_LEFT);      // blocks for the whole scroll
```

`endText(SCROLL_LEFT)` **does not return until the animation finishes** —
several seconds. In a standalone sketch that is fine. In a
[transponder](10.4-transponder.md) it is not: `loop()` stops pumping serial,
so arm traffic is dropped and host calls stall every time the message loops.

## Non-blocking approach

Render one column-shift per `loop()` iteration and return immediately between
ticks:

```cpp
static void tickMatrix()
{
    uint32_t now = millis();
    if (now - last_scroll_ms < SCROLL_MS)
        return;                      // not yet — return at once
    last_scroll_ms = now;

    uint8_t frame[8][12];
    for (uint8_t x = 0; x < 12; x++) {
        uint8_t bits = textColumn((scroll_col + x) % total);
        for (uint8_t row = 0; row < 8; row++)
            frame[row][x] = (row < 7) ? ((bits >> row) & 1) : 0;
    }
    matrix.renderBitmap(frame, 8, 12);

    if (++scroll_col >= total)
        scroll_col = 0;
}

void loop()
{
    pumpHostToArm();
    pumpArmToHost();
    tickMatrix();
}
```

`renderBitmap(bitmap, rows, cols)` takes a row-major `uint8_t[8][12]`, one
element per pixel. It is a macro over `loadPixels()`.

Measured with this running, 40 consecutive `get_angles()` calls returned
0 malformed replies at a median of 17.8 ms — the display costs nothing
measurable.

## Font

A 5x7 column-major font covering `A-Z`, `a-z`, `0-9` and space, at 5 bytes per
glyph. Bit *n* of each byte is row *n*, top-down; descenders on `g j p q y`
occupy row 6, inside the 7-row cell.

```c
{0x7F, 0x02, 0x0C, 0x02, 0x7F},  // M
{0x7C, 0x04, 0x18, 0x04, 0x78},  // m
```

Characters are spaced 6 columns apart (5 glyph + 1 gap).

## Configuration

```c
static const char MSG[] = "ER myCobot 280 UNO R4 ";
#define SCROLL_MS  90       // lower = faster
```

Keep the trailing space — it separates the end of the message from the start of
the next loop.

A complete implementation is in
[MyCobot280_R4_Transponder](https://github.com/vhp8rc7p/MyCobot280_R4_Transponder).
