# 6.1.1 Environment Construction

## Arduino IDE

Download and install the Arduino IDE from the
[Arduino website](https://www.arduino.cc/en/software). Version 2.x is
recommended; the examples here were built with the IDE 2.x bundled
`arduino-cli` 1.4.1.

## Board package

The UNO R4 needs the Renesas core, which is **not** installed by default.

**Tools → Board → Boards Manager**, search for **Arduino UNO R4 Boards**, and
install it (package id `arduino:renesas_uno`).

Unlike the M5 build, you do **not** need:

- the M5Stack board-manager URL,
- the M5Stack board package,
- the CP210x or CH9102 USB-serial driver.

The UNO R4 enumerates as a native USB CDC device and needs no driver on
Windows 10/11, macOS or Linux.

## Verify the board is detected

Plug the R4 in and check **Tools → Port**. From the command line:

```
$ arduino-cli board list
Port  Protocol Type              Board Name          FQBN                          Core
COM13 serial   Serial Port (USB) Arduino UNO R4 WiFi arduino:renesas_uno:unor4wifi arduino:renesas_uno
```

If nothing appears, try a different USB cable before anything else — charge-only
cables are a common cause and carry no data lines.

## Python host software

For [transponder mode](10.4-transponder.md), the PC needs `pymycobot`:

```
pip install pymycobot
```

These pages were verified with `pymycobot` 4.0.6 on Python 3.13.
