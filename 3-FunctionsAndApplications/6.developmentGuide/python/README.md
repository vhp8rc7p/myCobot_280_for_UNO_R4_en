# 6.2 Development and use based on Python

With the R4 running [transponder mode](../Arduino/10.4-transponder.md), the
host-side Python API is **exactly the same** as for an M5 build — `pymycobot`
cannot tell the difference, because the serial protocol is identical.

Everything in the official Python guide applies. These pages cover only what
is specific to, or commonly trips people up with, the R4.
