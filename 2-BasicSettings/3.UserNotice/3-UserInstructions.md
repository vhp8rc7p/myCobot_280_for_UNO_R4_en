# User Notice

This topic is **independent of which controller board you use**. The arm
hardware, and therefore this information, is identical whether the base is
driven by an M5Stack Basic or an Arduino UNO R4.

Rather than restate it (and risk it drifting out of date), refer to the
official documentation:

**[User Notice — official myCobot 280 documentation](https://github.com/elephantrobotics/mycobot_docs/tree/main/myCobot_280_for_Arduino_en/2-BasicSettings/3.UserNotice/3-UserInstructions.md)**

Safety guidance applies unchanged. One addition specific to this setup: see the 5 V / 3.3 V warning in [5.3 Hardware Interface](../../3-FunctionsAndApplications/5.BasicFunction/5.3-HardwareInterface/RoboticArmElectricalInterface.md).
