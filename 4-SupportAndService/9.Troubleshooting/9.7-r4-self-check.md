# 9.1 First-time self-check

## Before connecting the arm

1. **Board package installed** — Tools → Board shows "Arduino UNO R4 Boards".
2. **Board enumerates** — the R4 appears under Tools → Port. If not, try
   another USB cable before anything else; charge-only cables carry no data
   lines and are a common cause.
3. **Library configured** — the **root** `ParameterList.h` has `MyCobot_M5`
   commented out and `MyCobot_Mkr` enabled. See
   [6.1.2 Simple Use](../../3-FunctionsAndApplications/6.developmentGuide/Arduino/10.2-arduino_use.md).
4. **A sketch uploads** — `Mkr/AnglesControl` compiles and flashes.
5. **Firmware responds** — with the transponder flashed, and with no arm
   attached:

   ```
   send: fe fe 02 c1 fa
   recv: fe fe 03 c1 18 fa
   ```

## Then connect the arm

Power the arm down, wire D0/D1/GND crossed as in
[5.3 Hardware Interface](../../3-FunctionsAndApplications/5.BasicFunction/5.3-HardwareInterface/RoboticArmElectricalInterface.md),
then power up.

6. **Arm responds** — `mc.get_system_version()` returns a number.
7. **Telemetry works** — `mc.get_angles()` returns 6 values.

## Before the first commanded move

The first `send_angles()` will swing several joints at once. Before running it:

- confirm the workspace is clear,
- use a low speed (20 is a reasonable first value),
- be ready to cut arm power.

Read the current pose first so you know how far it will travel:

```python
print(mc.get_angles())
```
